Playground'dan API Gateway'e

ücretsiz.ai, ücretsiz AI modellerini denemek için başladı. Vizyonumuz çok daha büyük: geliştiricilerin tek bir anahtarla onlarca AI sağlayıcısına erişebildiği, sonrasında kendi AI altyapımızı sunduğumuz bir platform olmak.

Yol Haritamız

Üç aşamalı bir büyüme planı üzerinde çalışıyoruz.

Aşama 1 · Şu An

Ücretsiz Model Playground

30+ ücretsiz ve ücretli yapay zeka modelini keşfedin, Türkçe performans skorlarıyla karşılaştırın ve kendi OpenRouter API anahtarınızla doğrudan sohbet edin.

  • Model keşfi ve karşılaştırma
  • Ücretsiz canlı sohbet arayüzü
  • API entegrasyon örnekleri (cURL / JS)
Aşama 2 · Sırada

Birleşik API Gateway

Onlarca sağlayıcıyı tek bir API anahtarı ve tek faturalandırma altında birleştiren bir gateway katmanı. Geliştiriciler tek entegrasyonla tüm modellere erişir.

  • Tek anahtar, çoklu sağlayıcı erişimi
  • Kullanım bazlı, şeffaf fiyatlandırma
  • Gelişmiş izleme ve limit yönetimi
Aşama 3 · Sonra

Kendi AI Altyapımız

Gateway deneyiminden edindiğimiz bilgiyle kendi model sağlayıcılığımıza ve altyapımıza doğru genişleyen uzun vadeli bir hedef.

  • Kendi barındırılan modellerimiz
  • Kurumsal ölçekte SLA ve destek
  • Türkçe'ye özel optimize edilmiş modeller
