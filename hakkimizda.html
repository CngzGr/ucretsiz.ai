Sıkça Sorulan Sorular

ücretsiz.ai gerçekten ücretsiz mi?

Evet! Site tamamen ücretsiz ve açık kaynaklıdır. AI modellerini kullanmak için OpenRouter'dan ücretsiz bir API anahtarı almanız yeterlidir. Ücretsiz modeller için herhangi bir ücret ödemeniz gerekmez.

API anahtarım güvende mi?

API anahtarınız yalnızca tarayıcınızın localStorage'ında saklanır ve doğrudan OpenRouter API'sine gönderilir. Bizim herhangi bir sunucumuza iletilmez. Site tamamen istemci tarafında (client-side) çalışır.

Hangi AI modellerini ücretsiz kullanabilirim?

Google Gemini 2.0 Flash, Meta Llama 3.3 70B, DeepSeek V3/R1, Qwen 2.5 Coder, Mistral 7B ve daha fazlası OpenRouter üzerinden ücretsiz olarak kullanılabilir. Tüm modelleri görüntüleyin →

OpenRouter API anahtarını nasıl alabilirim?

1. openrouter.ai adresine gidin.
2. Google veya GitHub hesabınızla ücretsiz kayıt olun.
3. openrouter.ai/keys sayfasından yeni bir API anahtarı oluşturun.
4. Anahtarı kopyalayıp sitemizin Ayarlar bölümüne yapıştırın.
