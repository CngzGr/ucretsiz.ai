Sıkça Sorulan Sorular

Ücretsiz.ai gerçekten ücretsiz mi?

Evet! Site tamamen ücretsiz ve açık kaynaklıdır. AI modellerini kullanmak için OpenRouter'dan ücretsiz bir API anahtarı almanız yeterlidir. Ücretsiz modeller için herhangi bir ücret ödemeniz gerekmez.

API anahtarım güvende mi?

API anahtarınız yalnızca tarayıcınızın localStorage'ında saklanır ve doğrudan OpenRouter API'sine gönderilir. Bizim herhangi bir sunucumuza iletilmez. Site tamamen istemci tarafında (client-side) çalışır.
